# Глоссарий проекта CineShelf

| Термин (RU / EN) | Определение и контекст использования в системе |
| :--- | :--- |
| **CineShelf** | Web-приложение (Java, Spring Boot, PostgreSQL) для ведения личной коллекции фильмов, списка «План к просмотру», выставления оценок, личных заметок/отзывов и просмотра статистики. |
| **Гость (Guest)** | Неавторизованный посетитель web-приложения; просматривает публичный каталог фильмов, карточки фильмов и агрегированные данные без доступа к личным спискам и изменению данных. |
| **Пользователь (User)** | Зарегистрированный пользователь системы; управляет личным «Планом к просмотру», отмечает фильмы просмотренными, ставит или изменяет оценки (1–10), ведёт личные отзывы и смотрит личную статистику. |
| **Администратор (Administrator)** | Роль с правами управления контентом и модерации: добавляет и редактирует фильмы, переводит фильмы в архив, ведёт справочник жанров и выполняет модерацию оценок. |
| **Каталог фильмов** | Общий перечень фильмов с пагинацией, поиском по названию, фильтрацией по жанру и сортировкой, поддерживаемый администратором. |
| **Карточка фильма (Movie)** | Сущность фильма в каталоге, содержащая название, год выпуска, длительность (мин), описание, список жанров, среднюю оценку, число оценок и признак архивации. |
| **Жанр (Genre)** | Элемент справочника жанров (`id`, `name`), связываемый с фильмами; при наличии привязанных фильмов не удаляется без снятия связей. |
| **Архивный фильм** | Фильм в состоянии архива (`isArchived = true`): скрыт из каталога и недоступен для нового добавления в план, но сохраняется в истории и списках пользователей с прежними оценками. |
| **План к просмотру (Watchlist)** | Личный список фильмов пользователя со статусом `Planned`, датой добавления, приоритетом (`High`, `Medium`, `Low`) и заметкой; дубликаты для одного пользователя запрещены. |
| **Просмотренный фильм** | Запись фильма в коллекции пользователя со статусом `Watched` и датой просмотра; при переводе в просмотренные автоматически убирается из плана к просмотру. |
| **Оценка (Rating)** | Целочисленная оценка фильма пользователем по шкале от `1` до `10` (на пару «пользователь — фильм» допускается одна актуальная оценка; повторная заменяет прежнюю). |
| **Средняя оценка** | Агрегированное среднее значение оценок фильма по всем пользователям, округляемое до `0,1` и пересчитываемое с защитой от гонок при конкурентных запросах. |
| **Личный отзыв** | Текстовая заметка пользователя к оценке (до 1000 символов), видимая только самому пользователю. |
| **Модерация оценок** | Действия администратора по проверке и скрытию/удалению некорректных или манипулятивных оценок с последующим пересчётом средней оценки фильма. |
| **Личная статистика и Топ-10** | Личные показатели пользователя (число просмотренных фильмов, средняя личная оценка, топ-3 жанра) и рейтинг топ-10 фильмов при достижении порога оценок. |
| **Оптимистичная блокировка** | Механизм контроля конкурентных обновлений при изменении оценок и пересчёте агрегатов без долгих пессимистичных блокировок на время чтения. |
| **JWT (JSON Web Token)** | Токен аутентификации и авторизации для доступа к защищённым эндпоинтам API и ролям пользователей с ограниченным временем жизни сессии. |
| **Поток событий (Flow of Events)** | Структурированное описание сценария прецедента: назначение, предусловия, основной поток, альтернативные потоки, потоки исключений и постусловия. |
