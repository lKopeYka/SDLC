# CineShelf — сквозной проект курса ЖЦРПО

Web-приложение для ведения личной коллекции фильмов, управления планом к просмотру и выставления оценок
(Java 21, Spring Boot 3, PostgreSQL 16, HTML/Thymeleaf).

Автор: Ямонт М.Д., гр.450501, БГУИР, кафедра ЭВМ.
